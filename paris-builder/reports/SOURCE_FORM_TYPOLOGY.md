# 源作品的形态分类（结构层的第一份依据）

依据：`runs/SOURCE-FORMS-SHEET.png`（14 张源作品总览并排）。**逐个看图得出，不是猜的。**

## 关键发现：14 个源作品跨越 5 类形态，不是同一种公寓楼

| 类别 | 源作品 | 可观察到的形态特征 |
|---|---|---|
| **A 市政/纪念性** | building1、building3?、building5、building7 | 低而长的体量、巨型壁柱贯通主体、重檐口、陡芒萨尔 + 中央塔楼/角亭、栏杆与尖顶饰 |
| **B 宫殿/府邸（带翼与柱廊）** | building4、building6、building3 | 中央主体 + 两侧翼、柱廊/连拱廊、**内院或前院**、端部亭子独立于主体 |
| **C 转角公寓** | building2、street1 | 街角主体、**斜切角（pan coupé）**、转角塔亭/穹顶、重装饰芒萨尔、底层商铺 |
| **D 连续街墙** | street3、street7、street2 | 沿街连续排布、**每户立面略有差异**（异质拼贴）、统檐口线、底层商铺带、女儿墙/芒萨尔混合 |
| **E 坡地/沿街商铺长排** | street4-slope、street5、street6 | 依坡而建、斜切角正对街口、长排店面（street5 五六个店面并列）、窄面深进深（street6） |

## 这直接说明我此前的错误

我此前的"结构层"只有 `open_court / enclosed_court / l_plan` 三种平面 + 4–5 层 + 固定层高 7，
那是**只覆盖 C 类（转角公寓）的一个变体**。所以：

- A/B 类（市政、府邸）**根本造不出来**；
- D 类（连续街墙）**造不出来**——我的生成器只造"独立单栋"，没有"贴邻接山墙、只做临街面"的概念；
- E 类（坡地、长排店面）**造不出来**——没有地形、没有多店面节奏。

## 结构层需要的最小自由度（从这 14 个反推）

1. **体量拓扑**：单栋四面 / 街墙（单面临街 + 邻接山墙）/ 主体+翼 / 带内院回折
2. **楼层制度**：层高（不是固定 7）、层数区间、**是否有 entresol（夹层）**、
   **étage noble（主层）在哪一层**、是否有退层（attique en retrait）
3. **垂直分段**：基座 / 主体 / 檐部 各自的层数与处理（A、C、D 类都有明确三段）
4. **转角处理**：无 / 斜切 pan coupé / 塔亭 / 穹顶 / 加宽转角开间
5. **屋顶形式**：芒萨尔（陡）/ 芒萨尔（带脊饰冠）/ 双坡 / 平顶女儿墙 / 中央塔楼
6. **中轴处理**：无 / 中央亭凸出 / 贯通多层的巨型壁柱 / 钟塔
7. **临街面制度**：单面临街 / 双面临街 / 转角三面 / 街墙（只处理一面，其余为山墙）
8. **地形**：平地 / 坡地（street4）

## 现实依据（联网核对，与上图一致）

- 巴黎建筑的类型学区分**"immeuble de rapport"（出租公寓）与 "hôtel particulier"（府邸）**是两个不同体系，
  后者常为"entre cour et jardin"（前后院之间）；我的 14 源里 B 类正是这一支。
  [hicsa.pantheonsorbonne.fr](https://hicsa.pantheonsorbonne.fr/sites/default/files/2023-08/marantz_2021_01book.pdf)
- 奥斯曼式街区的典型组合是**底层 + 夹层 + 五层方形层 + 退层**（rez-de-chaussée, entresol,
  cinq étages carrés et un étage en retrait），这直接对应上面第 2 条"楼层制度"。
  [plui.ampmetropole.fr](https://plui.ampmetropole.fr/assets/documents/PLUi_CT1_R1_AVAP_SPR_2_Rglt_T2_Th3_EspBati_11_Sequence_13002.pdf)
- APUR 的城市形态研究明确指出**"转角"是一个独立的设计问题**，不是两面墙的简单相交，
  这对应上面第 4 条。[50ans.apur.org](https://50ans.apur.org/data/b4s3_home/fiche/82/03_immeuble_espace_urbain_tome3_apapu100-2_7cb38.pdf)

## 实测：从你自己素材里量出来的尺度（`tools/measure_source_parcels.py`）

全 14 源实测，写入 `knowledge/city/measured_source_parcels.json`：

| 量 | 实测值（方块） | 说明 |
|---|---|---|
| 临街段宽（可识别的单元/联排段） | **6 / 11 / 12 / 27 / 34 / 42 / 48**（中位 27） | 单个单元约 12–27，整段联排 27–48 |
| 建筑总高 | 中位 **44**，范围 35–61 | |
| 进深 | 23 – 244（多数 23–136） | 进深常**大于**面宽，是巴黎地块的典型特征 |
| 单体包络 | 最大 350×133 | 有整条街的作品（民居街区7 = 350 长） |

**结论（对结构层的要求）**：

1. **地块窄面宽、大进深**，联排段长 27–48 格 → 结构层必须支持"**连续街墙**"（多单元拼一段），
   而不是我一直做的"独立单栋四面"。
2. **总高 35–61 格** 与我的生成器（40–50 格）**量级一致** —— 所以问题不是"太矮"，
   而是**层内细分不足**：你的作品在一层里分出窗台/窗楣/横向线脚多个高度带，
   我的生成器一层就是"一个大窗洞"。
3. **存在 350 格长的整条街作品** → 城市层不需要我发明街道，**你的素材里已经有街**，
   应该按你已有的街道尺度来铺。
