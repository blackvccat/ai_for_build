# 两组参考源的实际拆解与清洗

本轮任务是理解参考建筑的建造手法，给单栋设计提供依据。参考图用于方向；提取和测量依据是对应的 `巴黎民居街区3.schem` 与 `巴黎建筑素材2.schem`。原文件与 `_incoming_schematics` 中的副本 SHA256 分别一致，源文件保持不变。

## 查出的旧数据错误

- `survey_incoming.py` 使用 `volume > 0` 判断非空气，并从调色板编号 1 开始统计。街区3的空气编号恰好为 1，因此空气被计为实体、0号真实材料被漏计。真实非空气为 **54,746 / 340,000（16.10%）**；旧报告的 **332,802（97.88%）** 和“填充体无细节”结论无效。
- `extract_details.state_grid()` 也把0号材料强制改为空气；`clean_cut()` 返回共享数组，随后规范化门叶会污染后续重叠裁件。两处已修正。
- 旧门叶清洗记录中的“original_door_states”曾把改写后的状态计入原始账目，已修正记录函数。更重要的是，源街面确实用铁门薄模型做窗面，不能把连续 `half=lower` 自动当作功能门损坏。通用提取默认保留状态，只有显式指定功能门清洗才改写。
- 修正后重新测量全部43份输入，均为可进一步检查的源；“有资格检查”不代表手法优良或语义拆解完成。历史 v2 中8件受0号材料问题影响、76件发生门叶改写，共84件进入待重拆清单，默认检索不再推荐。历史文件和直接ID访问保留。

## 从源里理解到的关系

街区3的第三段可见街面是23格宽。y=22、z=26..27测到5组两格宽薄窗面，起点间距是 **4、5、5、4格**，并非机械等距。主体窗面高度区间是 `[8,12)、[14,18)、[20,24)、[26,30)`，顶层另用 `[33,36)`。这一组局部测量给出主体6格重复及顶层变化，不能推广成所有巴黎建筑的定值。

薄窗面来自前后相反朝向的铁门模型；铁栏、砂岩墙肢和半砖在外侧组成护栏、窗套和窗台。屋顶窗有独立直立窗面及收头；屋面剖条显示由街面陡段向上部缓段的退距。烟囱采用细立管，并用铁砧、花盆收头。这些具体做法都能回到裁件坐标和状态，而不是只凭构件名称类比。

素材2的高基座、成组窗、壁柱与多道檐口体现另一种尺度。它的复杂屋面、转角及后部体量不能整体缩成12格街屋；单栋应选择完整开间，重新组织入口、两侧墙墩和屋面比例。此轮交付的是学习材料及匹配约束，没有把旧候选房屋标为设计通过。
