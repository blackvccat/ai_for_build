## 2. 跨源规律（按元素）

### 2.1 窗面：薄窗面三明治是主导的窗做法（5 源以上独立使用）

- **构造公式**：外层（活板百叶/铁栏）→ **门叶薄窗面**（两列 facing 相对、全部 `half=lower`）→ 玻璃背衬 → 深色内衬。
  st1 达四层（`st1-window-bay-noble`：活板/铁栏 → 双层铁门 → 白玻璃 → 凝灰岩/玄武岩/深板岩内衬）；
  st7 橡木版达六层（`st7-window-screen-oak`：装饰屏 → 阳台 → 橡木门面 → 铁活板百叶 → 避雷针竖梃 → 青玻璃）。
- **门叶 `half=lower` 冻结态是手法本体，不是缺陷**（v3 清洗已纠正"自动配对"错误；源依赖禁止更新粘贴）。
- 材料族对照：铁门版（s3/st5，配白玻璃+实体墙）、橡木版（st7，配青玻璃+铜避雷针）、诡异木版（st5/st6 店面系）。
- **楼层分级**：贵族层 = 通高两档窗 + 石栏板阳台 + 横梃（st1/b1/st4）；标准层 = 简化（st1-standard/s3）；
  阁楼 = 盲窗/小窗（b6-window-bay-north 的空腹暗窗、st7-parapet 的一开一盲）。
- 窗台：磨制黑石压力板 `powered=true`（st1/st4，刻意冻结的装饰态）、半砖+拉杆牛腿。
- 开间墙墩：`sandstone_wall` 冻结连接态（`up=false`、单向 `low/tall`）——薄墩是幽灵墙冻结写法。

### 2.2 转角：五族对照与选择条件

| 族 | 代表件 | 构造要点 | 适用 |
|---|---|---|---|
| 切角 pan coupé | 街区3 西端、`b7-corner-chamfer-west` | 切面自成窄立面（勒脚台阶+角柱墩+女儿墙收分三段阶梯自立）；45° 对角 1×1 阶梯 | 转角公寓（最奥斯曼） |
| 圆弧转角 | `b2-corner-body-1/2`、`st4-corner-rounded-body` | **45° 对角玻璃带阶梯逼近**：每步错 0–1 格、宽度 1/2/3/4 展开（b2）；两级半径、绕弧阳台（st4） | 大尺度转角楼 |
| 船头尖角 | `st4-prow-base/body/rooftip` | **非对称收头**：一侧端柱平收、一侧 45° 阶梯包角绕合；曼萨德顶帽在尖端合拢；窗轴竖直随阶梯错位 | 楔形地块 |
| 角亭纪念化 | `b1-corner-pavilion-body/cap`、`st1-corner-turret-*` | 转角拔高 + 独立顶冠（金字塔顶/高陡屋顶亭）+ 望楼平台尖饰组；主次转角分等级 | 市政/重要街角 |
| L 形凹角 | `b5-corner-chamfer-*` | 两面墙退让出向街开放的小庭、回头墙做雕像龛、隅石墩逐层换材收角、檐口桥接凹角上空（"墙退檐进"） | 市政/退让式转角 |

要点：转角是**独立设计问题**——五族没有一族是"两面墙简单相交"；转角件的构造（阶梯逼近/收头/绕角带）都可以参数化。

### 2.3 店面：语汇要素与真假交替

- **语汇要素**（对照卡 shopfront.png，12 件）：橱窗（玻璃后退一格 / 瓦楞楼梯背板 / 潜影盒展台）、竖梃（栅栏门 open 折回 / 避雷针 / 蘑菇茎 / 链条）、招牌带（y4–5：去皮木 / 羊毛 / 潜影盒）、雨棚披檐（活板/楼梯/半砖通长）、门槛（楼梯 bottom / 棋盘地面）、凹廊真开口（st5-c，6 格深）。
- **真假交替**：真入口（凹入一格空气壁龛）与假窗（门薄窗面）按模数交替——st7-warped-corner 是 4 格循环「墩跨→A窗→入口壁龛→B窗」×3。
- **彩色木作是巴黎感来源**：朱红 mangrove 门柱（st4-red，门叠 6 格仅底部配对）、青绿 warped 雨棚（st4-awning 八格连续）、蓝潜影盒招牌带（st7）。
- **斜面店面**：1×1 阶梯对角线，橱窗门叶 `facing` 按踏步朝向二选一，让 3px 门端薄棱始终正对读者（st7-warped-corner，逐格实测）。
- 店内"货架灯"：矿石/sculk/菌岩陈列层透光（街区7 全族共用；st6-shopfront-white 反向做法：整片白混凝土衬墙不做玻璃）。

### 2.4 老虎窗：双排制与等级编码

- **双排制**：下排嵌陡坡脚、上排立坡折上方缓坡——st1/st4/b2 三源独立出现，升格为规律。
- **颊板材料编码开间等级**：白安山岩=普通开间、深板岩=凸出体/上层、方解石=山花旁（st1 系）；st4 按高度分级（整玻璃亮窗 → 玻璃板+白框 → 深颊板）。
- 构造公式：直立窗面（门薄窗面或玻璃）+ 颊板 + 小顶帽 + 窗台（压力板）+ 点缀（凋零玫瑰）。
- 与屋面关系两制：凸出（多数）vs 齐平嵌合（`b6-dormer-west`）。

### 2.5 烟囱：成组、立脊、必有收头

| 件 | 做法 |
|---|---|
| `st1-chimney-group` | 棕蘑菇块+花岗岩烟囱墙，**红花盆列当雉堞**；旁立苔石杆（全楼 0 个 bricks） |
| `st4-chimney` | 石砖/石头/安山岩逐层换材叠柱 + 红花盆收头 |
| `s3-chimney` | 细立管 + 铁砧/花盆收头 |
| `b1`（金冠，未单裁） | 金饰烟囱 |
| `b6-roof-section` 内 | 真红砖双烟囱 + 盲砖山墙 |

共同律：成组出现、锚在屋脊/坡顶、顶部必有收头（花盆/铁砧/金饰）。"红砖感"多数用蘑菇块/花岗岩达成而非红砖。

### 2.6 檐口与线脚

- **多道叠涩**：楼梯/半砖/墙层层外挑（b1 含粉羊毛嵌饰带；b6 三重墙柱头叠涩+骨块牙子）。
- **齿饰带**：绊线钩（st1）、砂轮（st4）、**横放链条当金属线脚**（b1 y10 贯通整条立面，此源最强细部签名）。
- 顶栏：瓮饰栏干（b1）、望柱栏干（b6）。
- 与屋顶衔接：深色天沟接曼萨德起坡（st1-cornice）。

### 2.7 阳台

- 连续带可绕角：st4 橡木楼梯带（`inner/outer` 形状成体系绕弧）、b2-corner-body-2 绕弧连续阳台。
- 栏干三族：铁栏 X 格（st1）、讲台栏柱（st4）、砂岩墙 `up=false` C 形通透栏（b2-roof-cresting）。
- 台面/压顶：桦木+压力板（st1）、磨制黑石压力板 `powered=true`（st4）。
- 牛腿：**拉杆成排体系**（st1，每条挑台下一排拉杆）。
- 种植系统：珊瑚/玫瑰/荧光地衣在每个带、檐口、窗台、屋脊成排（st1 全楼）。

### 2.8 壁柱与柱廊

- 巨型贯通柱：b1（砂岩芯+棕色竖槽+卵石横带+干草块金垫柱头，开间骨架 7 宽=2 柱+5 窗）、b5（橡木栅栏外棱+按钮钉+蜂巢红头）。
- **柱廊圆柱做法**（`b6-colonnade-bay`）：2×2 `diorite_wall` 冻结连接态拼圆面；柱头=砂岩→苔石→圆石三重墙由细到粗模拟外挑；蘑菇柄柱础。
- **柱廊是双层立面**：柱线（z=82-83）与玻璃内墙（z=78）之间是可通行凉廊（铁栏+蜡烛+吊链灯）——"柱廊遮阳+内墙采光"完整纵深。

### 2.9 屋顶

- 曼萨德剖面公式：檐沟 → 陡坡 → 坡折 → 缓坡 → 屋脊（`st1-roof-section` 全剖件，3×17×39）。
- **坡面必须有肌理**：st1 陡坡 = 黑石/玄武岩/灰混凝土/凝灰岩杂混——单一深色壳即"我的世界感"的死因（生成器旧楼的屋顶正是如此）。
- 屋脊处理三族：脊栏（b1 双道）、种植床（st4）、M 形双脊并合（st4-roof-section）。
- **一建筑两屋顶制度**是合法的：b1 北翼露台筒拱 vs 东翼曼萨德；b6 北翼曼萨德 vs 西翼老虎窗。
- 负发现：b7 筒拱"光眼"是实心浅材图案（非天窗）；b6 内院四面全素（面子工程做法，与真实府邸相反，已入账）。

### 2.10 基座与入口

- 粗石凹砌墩 + 拱龕（`b1-base`、`st1-base-arcade`：深板岩拱腹暗衬、铁门扇深衬、干草块拱肩金垫）。
- 入口深门膛：`st1-base-entry`（宽拱+石板台阶+铁栅门洞）；`b6-entry`（**虚开间**：三格全空通道+吊链灯——门以"空"表达，全源无真实门扇）。
- 拱的表达两制：b6 由墩顶层线表达、洞口矩形；b7 拱环 z 前挑 1–3 格 + y 向放级收环宽（`b7-arch-window`）。

## 5. 负发现（实测否定，同等重要）

1. 素材5"切角"实为 L 形凹角小庭（普查情报纠偏）。
2. 素材7 屋顶无老虎窗、无玻璃天窗（光眼=实心图案）；筒拱+穹顶。
3. 素材6 内院四面全素（0 特征列）——"外面精装、内院全素"是源的真实做法。
4. 街区4 无地形高差（"斜面"=平面斜向）；素材5 是实心羊毛填充模型（装饰壳 4–5 格）。
5. b1/b5/部分 st1/st4 件含 `create:cut_calcite_wall` 模组壁柱（19 件标 `compatible_vanilla=false`，追溯专用，不进 vanilla 装配；装配用件须选 vanilla 替代面）。
6. 街区7 立面是 6 层装饰壳贴灰色实芯体（`st7-facade-unit` 实证）——"壳体做法"是源建筑的普遍结构。

## 6. 对生成器细节层的要求（第④步输入）

1. **技法层 = 库件组装引擎 + 参数化填充**：按"形态类 × 元素 × 等级"从本矩阵选件；开间节距=件宽+墙墩宽（手法决定开间，反转现行顺序）。
2. **每个元素至少 2 变体 + 等级编码**：窗（贵族/标准/阁楼）、老虎窗（下排/上排 × 白颊/深颊）、店面（≥3 变体彩色木作）。
3. **屋顶必须成套**：曼萨德剖面 + 坡面肌理混合 + 双排老虎窗 + 烟囱组 + 脊饰 + 檐口齿饰，缺一即为旧楼的"黑壳"病。
4. **每一面有显式处理决策**（含"此面不可见从简"的声明与理由）；转角按五族之一处理，不允许"两面墙直接相交"。
5. **冻结状态随件携带**：stamp 逐格审计（`verify_stamp_audit`），未在 state_context 白名单内的挪用品状态不得新造（游戏内 STATE-LAB 验收前）。
6. 店铺/入口要有**真假交替**节奏（真空气壁龛+假窗面）；阳台带遇转角必须绕角或显式收头。
